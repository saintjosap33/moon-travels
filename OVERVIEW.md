# Moon Travels - App Overview

## What is Moon Travels?

Moon Travels is a **complete Travel Agency Management System** designed for travel agencies to manage their business operations end-to-end. It's built as a college Database Management Systems (DBMS) project to demonstrate real-world database design, normalization, and SQL operations.

## Who Uses It?

- **Travel Agency Owners/Managers**: Oversee all operations
- **Travel Agents/Staff**: Create bookings, manage customers, process payments
- **Students/Educators**: Learn database design, normalization, and SQL through a real application

## Core Business Workflow

The application supports the complete travel booking lifecycle:

1. **Customer Management** → Add and track customers
2. **Package Selection** → Browse travel packages with destinations and accommodations
3. **Booking Creation** → Create bookings with multiple passengers
4. **Passenger Details** → Add passenger information for each booking
5. **Payment Processing** → Record payments (multiple payments per booking supported)
6. **Receipt Generation** → Print professional receipts
7. **Income Tracking** → Monitor revenue and outstanding payments
8. **Reporting** → Generate business reports and analytics

## Key Capabilities

### Management Modules
- **Customers**: Full CRUD for customer information
- **Travel Packages**: Create and manage travel packages
- **Destinations**: Maintain destination database
- **Accommodations**: Track hotels and lodging options
- **Transportation**: Manage flights, trains, buses
- **Bookings**: Complete booking management with passenger tracking
- **Payments**: Multi-payment support with status tracking
- **Receipts**: Professional receipt generation and printing
- **Reviews**: Customer feedback and ratings

### Financial Features
- **Income Dashboard**: Real-time revenue tracking
- **Payment Methods**: Cash, Card, Bank Transfer, UPI, Check
- **Outstanding Tracking**: Calculate unpaid booking amounts
- **Monthly Reports**: Revenue breakdown by month
- **Payment Method Analysis**: Income by payment type

### DBMS Educational Features
- **Schema Explorer**: View database structure
- **ER Diagram**: Visual database relationships
- **Normalization Guide**: 1NF, 2NF, 3NF explanations
- **Views & Indexes**: SQL views and indexing strategy
- **Transactions**: ACID properties and examples
- **Query Lab**: 10 SQL learning examples

## Database Design

The system uses a **fully normalized relational database** with:
- 15+ tables with proper primary/foreign keys
- M:N relationships via junction tables
- Referential integrity constraints
- Proper indexing for performance
- Real sample data (Indian travel agencies)
